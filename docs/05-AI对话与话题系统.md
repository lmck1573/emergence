# 05 · AI 对话与话题系统

> 职责：AI 交互界面的展示、话题列表、对话播放（逐字/跳过）、选择 UI、剧情演出指令的执行。
> **本系统不做条件判定、不改数值**——文本与结构全部来自 dialogues.json。

## 1. AI 交互界面构成

```
┌────────────────────────────────────────┐
│  [AI 形象区：眼睛/女主形象，含眨眼动画]      │  ← 上部居中
│                                        │
│  [人格完整度百分比显示]                    │  ← 形象区旁固定位置
│                                        │
│  （右上角：女主/AI 台词框，见 D20）          │
│  （左下角：男主台词框，见 D20）              │
│                                        │
│  [左下角功能 UI：退出到底图/投喂/话题]       │  ← docs/12
│  [存档按钮 + 音频开关]                    │  ← 右下角
└────────────────────────────────────────┘
```

AI 形象状态（与剧本一一对应）：

| 状态 | 时机 |
|---|---|
| 眼睛（闭→睁，循环眨眼） | 第一阶段全程 |
| 眼睛静止 → 后退 → 显示脸 → 上半身（坐书桌前，眨眼循环） | 第一阶段结束演出 |
| 上半身形象 | 第二阶段全程（微笑表情可切换，见 `portrait_smile`） |

开发期全部用色块/简单形状占位（眼睛=椭圆，女主=色块人形），眨眼动画用缩放占位。

## 2. 对话框（决策 D20）

| 说话者 | 位置 | 样式 |
|---|---|---|
| protagonist（男主） | 屏幕左下角 | 白色文本（P17 占位） |
| ai（女主/AI） | 屏幕右上角 | 浅青色文本（P17 占位） |
| system（提示） | 屏幕右上角（与女主同区域） | 灰色文本 |

规则：
- **无头像、无立绘、无角色名称标签**。
- 同一时刻只显示一个说话者的文本；切换说话者 = 切换文本框位置与样式，**禁止两个框同时出现或互相覆盖**。
- 第一阶段 AI 的机械说话风格（"喜欢 什么 电影？"）是**文本本身自带的空格**，排版时原样保留。

## 3. 对话播放

1. **逐字显示**：默认打字机效果；点击 → 立即显示整句（跳过逐字）；再次点击 → 下一句。
2. 末句播完后：有 `choice` → 显示选择 UI；无 → 对话结束，触发 `on_complete_*` 效果。
3. 对话播放期间：屏蔽其他一切输入（左下角 UI、场景点击全部失效）。
4. 对话由事件自动触发时：先自动切入 AI 界面再播放；播放完停在 AI 界面（不自动返回探索）。
5. **对话一旦开始必须播完**（没有中途退出；本游戏不存在可跳过的整段对话需求——跳过仅指跳过逐字效果）。

## 4. 话题列表（决策 D19）

| 规则 | 说明 |
|---|---|
| 入口 | 左下角功能 UI"话题"按钮 |
| 列表内容 | 只显示：当前阶段 + 已解锁 + `dialogue != null` 的话题（无对话配置的话题不显示，D14） |
| 无对话话题 | 不显示；**但若其"已完成"是事件条件，则在解锁时自动标记为已完成**（P19，如「锁上的电脑」话题），无需玩家操作 |
| 重复使用 | 已完成的话题可反复点击、反复播放对话；**重复对话不重复发放内容、不重复触发事件** |
| 阶段切换 | 列表清空，按新阶段话题重新生成 |
| 模态 | 打开期间底层禁点 |

## 5. 选择 UI

| 样式 | 用途 | 规格 |
|---|---|---|
| normal | 通用是/否确认 | 居中约 600×400，背景暗化（docs/12） |
| truth | 真相选择 | **红色、字体大一号**，"是/否"两项 |
| truth + selectable=false | 不可选演出（D10） | UI 照常显示，但**不响应任何点击**；显示 `locked_show_duration` 秒后被 `red_flood` 演出覆盖后消失 |

选择结果处理：
- 记录 `player_choice`（事件 ID + 选项），写存档。
- 播放 `branch_dialogue`。
- "是"才带 `add_truth_1` 效果（docs/07），"否"只记录。
- **同一事件的选择只结算一次**；已选择的事件再触发时恢复历史结果，不显示可重新选择的 UI。

## 6. 演出指令执行（封闭枚举，见 docs/02 §7）

- `black_flash`：全屏黑 0.3s → 恢复（EffectLayer 实现）。
- `red_heartbeat`：红色滤镜渐入 + 心跳音效 3 秒。
- `tinnitus`：耳鸣音效（可与红滤镜叠加）。
- `red_flood`：红色从边缘淹没全屏 → 停留 → 逐渐减退（约 3 秒全程）。
- 形象切换（`portrait_*`）：切换 AI 形象区显示状态。
- 演出指令执行期间对话暂停推进，演出完成自动继续。

## 7. 对外接口

| 接口 | 类型 | 说明 |
|---|---|---|
| `topic_completed(topic_id: String)` | 信号 | 话题对话首次完成时发 |
| `choice_made(event_id: String, option: String)` | 信号 | 选择结算时发 |
| `play_dialogue(dialogue_id: String)` | 方法 | 供事件系统/投喂系统调用 |
