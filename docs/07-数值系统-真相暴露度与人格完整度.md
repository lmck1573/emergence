# 07 · 数值系统 — 真相暴露度与人格完整度

> 职责：两个全局数值的读写与显示。**两个数值都只记录、只显示，永不阻断任何阶段推进**（P03）。

## 1. 真相暴露度 truth_revealed

| 项 | 规格 |
|---|---|
| 类型 | 整数，初始 0 |
| 增加途径 | **只有**真相选择的「是」选项（`add_truth_1` 效果），每个事件最多 +1（D07） |
| 本期真相事件 | U 盘剧情（第一阶段）、网文写作（第二阶段）——理论最大值 2 |
| 用途 | ① 聊天记录投喂分支（≥1 走 high 版本，docs/04 §4）；② 存档记录；③ 第三阶段结局判定（**本期不实现**，P03） |
| 禁止 | 用于门槛拦截、UI 显示（本期剧本未要求显示该数值） |

## 2. 人格完整度（决策 D05/D06）

### 2.1 计算规则

- **配置驱动**：每个可投喂内容带 `completeness_bonus`（contents.json），投喂结算时累加。
- **阶段区间**：第一阶段 0–40%，第二阶段 40–80%（第三阶段 80–100% 不实现）。
- **阶段转换校正**：`advance_phase` 效果执行时，完整度强制设为新区间下限（40.0 / 80.0）。U 盘真相无论选什么，转换后都是 40.0（"说出真相填补空缺"是叙事表现，数值上由转换校正统一处理）。

### 2.2 默认增量表（数值集中配置，策划可改，P07）

**第一阶段（区间 0–40，10 项投喂 × 3.96 = 39.6 = 阶段内 99%）：**

| 内容 | 增量 |
|---|---|
| hobby_movie / hobby_sweets / hobby_sunbath | 各 3.96 |
| exp_epiphyllum / exp_breakfast / exp_couple_bowls / exp_sunbath / exp_flowers / exp_lalaland / exp_dumplings | 各 3.96 |
| work_usb（U盘，经话题使用） | 0 |
| **阶段转换校正** | **→ 40.0** |

**第二阶段（区间 40–80，6 项投喂 × 6.6 = 39.6）：**

| 内容 | 增量 |
|---|---|
| work_diary / hobby_travel / hobby_plush（密码前） | 各 6.6 |
| hobby_games / work_chat_records / exp_webnovel（密码后） | 各 6.6 |
| exp_bills（奇怪的账单记录，可选） | **0**（可投喂但不计入完整度，否则超出 40-80 区间） |
| **第二幕结束校正** | **→ 80.0** |

### 2.3 显示

- 位置：AI 交互界面固定位置（形象区旁）。
- 格式：全局百分比，保留一位小数（P08），如 `36.3%`、`40.0%`。
- 变化即时刷新（`completeness_changed` 信号）。

## 3. 阶段转换流程（advance_phase 效果）

由阶段转换事件触发（docs/story），按序执行：

1. 播放转换演出/对话（第一阶段末：眼睛→上半身 +「新的外貌」「新的阶段」）。
2. `phase += 1`。
3. 完整度校正到新区间下限。
4. 清空投喂列表与话题列表的显示数据（D18/D19；历史状态保留）。
5. 解锁新区域（第一阶段末：女主房间）。
6. 标记转换事件完成 + 自动存档。

## 4. 对外接口

| 接口 | 说明 |
|---|---|
| `add_truth(n: int)` / `get_truth() -> int` | 真相暴露度 |
| `get_completeness() -> float` / `completeness_changed(value: float)` 信号 | 完整度 |
| `advance_phase()` | 仅阶段转换事件效果可调用 |

## 5. 自检清单

- [ ] 10 项投喂后完整度显示 39.6%；阶段转换后 40.0%
- [ ] 真相选择"是"后 truth 恰好 +1，重触发不加
- [ ] truth=0 时聊天记录走 low 版本，truth≥1 走 high 版本
- [ ] 两个数值都不阻断任何流程（truth=0 也能正常走完全部剧情）
