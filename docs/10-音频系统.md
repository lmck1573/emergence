# 10 · 音频系统

> 职责：统一的播放接口 + 音量总开关。**无剧情判定、无状态存储**（开关状态由 GameState settings 持有）。

## 1. 总开关

| 项 | 规格 |
|---|---|
| 形态 | 一个开关同时控制音乐与全部音效（本期无分通道音量，禁止开发音频面板） |
| 入口 | AI 界面右下角（与存档按钮并列，图标占位为文字按钮"声音：开/关"） |
| 关闭 | 所有正在播放的 BGM/音效立即静音/停止，新的播放请求被忽略 |
| 持久化 | 开关状态写入存档 settings |

## 2. 播放接口

| 接口 | 说明 |
|---|---|
| `play_cue(cue_id: String)` | 播放一次性音效（可带中断规则） |
| `play_bgm(bgm_id: String)` | 切换背景音乐（同曲不重启，切曲淡入淡出） |
| `set_muted(bool: bool)` | 总开关 |

**防叠音**：同一 `cue_id` 在 0.1 秒内重复请求只播一次。

## 3. Cue 清单（封闭枚举，本期全部；开发期全部静音占位，素材后补）

| cue_id | 时机 |
|---|---|
| `sfx_click` | 通用点击反馈（物体/按钮） |
| `sfx_feed` | 投喂操作 |
| `sfx_choice` | 选择按钮 |
| `sfx_save` | 存档完成 |
| `sfx_toast` | 提示浮层 |
| `sfx_floorboard_creak` | 主卧木板（点击时先于文本播放） |
| `sfx_window_creak` | 阳台防盗窗摇晃 |
| `sfx_lounger_rock` | 摇篮躺椅摇晃 |
| `sfx_fridge_open` | 冰箱打开 |
| `sfx_heartbeat` | 社交帐号剧情：心跳加快（伴随红色滤镜 3 秒） |
| `sfx_tinnitus` | 社交帐号剧情：耳鸣（心跳后触发） |
| `sfx_puzzle_correct` / `sfx_puzzle_wrong` | 密码判定 |
| `bgm_ai_interface` | AI 交互界面 |
| `bgm_explore_p1` / `bgm_explore_p2` | 探索（按阶段） |

BGM 切换规则：进入 AI 界面 ↔ 探索场景时切换；阶段转换时探索 BGM 换为对应阶段曲目。
