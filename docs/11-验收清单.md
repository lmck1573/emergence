# 11 · 验收清单

> 每项功能完成后按步骤实测，**界面能显示 ≠ 完成**。全部通过才算 P0 交付。
> 前置：每轮测试前删除 `user://save_data.json` 从新档开始（存档恢复类测试除外）。

## A. 场景与调查

**A1 场景切换**
1. 开场读完两份协议 → 进入俯视图
2. 依次点击客厅、厨房、阳台 → 各自进入正确特写
3. 每个特写点"退出到底图" → 回到俯视图
4. 俯视图点"电脑" → 进入 AI 界面；AI 界面"退出到底图" → 回俯视图
5. ✅ 全程无报错、无层级跳跃（特写不会直接跳到 AI 界面）

**A2 内容解锁（电视）**
1. 点击电视 → 独白播放 → 获得提示：爱好「看电影」+ 话题「电影」两条
2. 在 AI 界面完成「电影」话题对话 → 获得经历「一起看爱乐之城」
3. ✅ 三条内容分别入账（话题对话产出的经历单独发放，D01）

**A3 重复调查**
1. 再次点击电视 → 调查文本可重播
2. ✅ 内容不重复发放、toast 不再弹、完整度不重复加

**A4 特殊交互（情侣餐具/活页本）**
1. 点击情侣餐具 → 只有查看文本；未点"翻面"前内容列表无新条目
2. 点"翻面" → 获得「一起购买情侣餐具」+「同居第一天」
3. 活页本：查看→翻开→继续翻页 三步各播各的文本；末步获得线索「咖喱鸡排蛋包饭」
4. ✅ 重复翻面/翻页不重复发放

## B. 投喂与事件

**B1 投喂状态**
1. 投喂列表只出现当前阶段、已收集、未投喂的材料；线索（咖喱鸡排蛋包饭）不出现
2. 投喂任一材料 → 自动切 AI 界面播回应 → 该条目从列表消失
3. ✅ 已投喂材料无法再次投喂

**B2 条件触发（密码提示）**
1. 少投喂任一项（手账本/旅行/可爱的玩偶）或未完成「锁上的电脑」话题 → 提示事件不触发
2. 全部满足 → AI 界面自动搭话播放提示剧情，且只播放一次
3. ✅ 事件完成后重进 AI 界面不重播

**B3 密码解谜**
1. 提示事件后点电脑上锁交互点 → 轮盘锁
2. 输入错误密码（如 1234）→ 错误提示，可重试
3. 输入 1224 → 成功独白 + 三个文件夹出现
4. 退出重进电脑桌 → 已解锁状态，不再要求输入
5. ✅ 成功结算只有一次

**B4 真相选择**
1. U 盘剧情选「是」→ truth_revealed = 1；选「否」→ 0（分两次测试）
2. 同一事件二次触发 → 恢复历史结果，无可重选 UI
3. 网文真相选择同理
4. ✅ 每事件最多 +1

## C. 阶段与存档

**C1 阶段转换**
1. 完成主卧前置（11 交互点 + 10 项投喂 + 协议已读）→ 主卧解锁独白 → 主卧可进入
2. 获得U盘 → AI 界面使用 → 真相选择 → 阶段结束演出（眼睛→上半身）→「新的外貌」「新的阶段」对话 → 女主房间开放、阶段=2
3. ✅ 转换只发生一次；第二阶段开场不重播两段对话；完整度 = 40.0%

**C2 第二幕结束**
1. 投喂网文写作 → 真相选择 → 第二幕结束
2. ✅ 结束事件只触发一次；truth 与选择结果已存档

**C3 存档恢复**
1. 在第二阶段中期（部分投喂、密码已解）退出游戏 → 重进
2. ✅ 场景、阶段、内容、投喂、谜题、事件、选择、truth、完整度全部一致
3. 投喂/话题列表只含当前阶段未投喂材料
4. 事件播放中途杀进程 → 重进该事件从头重播

**C4 音效开关**
1. 关闭开关 → 所有声音静音；重进游戏保持关闭；重新开启恢复
2. ✅

## D. UI 补充验收

**D1 对话框位置**：男主台词出现在左下角、AI 台词出现在右上角，切换无覆盖；第一阶段 AI 台词的空格排版原样保留。

**D2 列表清空**：阶段切换后投喂列表与话题列表只含新阶段条目（旧阶段已投喂状态可从事件条件正常判定验证——如主卧条件在阶段 2 不再相关）。

**D3 话题重复**：已完成话题再次点击可重播对话，无重复发放、无重复 toast。

**D4 模态阻塞**：全屏文本/弹窗/列表打开期间，底层场景与左下角 UI 不响应点击。

**D5 提示浮层**：获得材料、解锁话题均为 toast；锁定区域点击出 toast"暂时无法进入"。

**D6 完整度显示**：AI 界面显示一位小数百分比；10 项投喂后为 39.6%，阶段转换后 40.0%。
