# 03 · 场景与调查系统

> 职责：场景层级与切换、交互物体的点击判定、二级操作状态、物体状态展示。
> **本系统不做任何剧情条件判定**——点击结果只上报 `GameState`，由事件系统决定后果。

## 1. 场景层级与导航（决策 D16）

```
AI 交互界面（开场场景，也即"电脑"）
   ↑↓
整屋俯视图（house_overview，探索枢纽）
   ↑↓                          ↑↓
区域特写：客厅 / 厨房 / 阳台 / 主卧 / 女主房间
   │
   └→ 子场景：电脑桌特写（computer_desk，从女主房间进入）
```

导航规则：

| 规则 | 说明 |
|---|---|
| 进入区域 | 俯视图点击对应区域（或 AI 界面"退出到底图"到俯视图后点击） |
| 返回上一级 | 左下角"退出到底图"按钮：区域特写 → 俯视图；电脑桌特写 → 女主房间；AI 界面 → 俯视图。**禁止跳过层级**（如特写直接退到 AI 界面） |
| 俯视图中 | "退出到底图"按钮隐藏；点击"电脑"区域进入 AI 界面 |
| 锁定区域 | 点击锁定区域 → toast 提示"暂时无法进入"，不进入场景 |
| 解锁后 | 区域永久保持开放（阶段内）；阶段切换不重新锁定已开放区域 |
| 场景切换 | 均带过渡（开发期为快速淡入淡出占位） |

## 2. 画面与坐标

- 逻辑画布 1920×1080；探索场景画布 960×960，居中（左上角约 (480, 60)）。
- 物体点击区域 = 相对场景原点的矩形（objects.json `click_area`），**禁止屏幕绝对坐标**。
- 点击判定：鼠标左键；多个区域重叠时取绘制顺序最上层。
- 开发期占位：场景背景 = 纯色 + 区域名；物体 = 半透明色块 + 名称 Label；提供调试开关显示全部点击框。

## 3. 交互物体的状态机

```
[锁定 conditions 未满足] → 点击 → toast"暂时无法交互"
[可用] → 点击 → 播放点击反馈(click_feedback，如有) → 进入步骤
[步骤 i] → 播放该步骤文本（全屏文本 UI）→ 步骤完成 → 发放该步骤 grants（去重）
    ├→ 存在下一步骤 → 显示二级操作入口（operation_label）
    └→ 无下一步骤 → 物体进入"已完成"
[已完成] → 再次点击 → 按 repeat_text_policy 重播文本，不发放任何内容
```

规则：

1. **重复调查永远允许**，重复点击不重复发放内容（去重按 content_id）。
2. 多步物体必须记录当前步骤进度（存档保存）；重新打开时从已完成进度继续，已翻开页面可重新查看。
3. 二级操作入口：完成步骤 i 后在物体上显示操作按钮（如"翻面""继续翻页"），点击进入步骤 i+1。**禁止把多步操作合并为一次点击**。
4. 物体"已完成"（全部步骤各执行一次）是主卧解锁等条件的判定单位。
5. 调查文本播放期间（全屏文本 UI 打开），底层场景禁止响应点击（模态阻塞）。

## 4. 特殊物体规格（本期全部清单见 docs/story）

| 物体 | 特殊行为 |
|---|---|
| 主卧木板 | 点击时先播放咯吱音效，再进入文本 |
| 冰箱 | 点击后播放"打开"状态反馈（占位：色块亮度变化），后续重复调查保持打开态 |
| 摇篮躺椅 / 防盗窗 | 点击反馈为摇晃 / 嘎吱响（占位：一次性位移动画 + 音效 cue） |
| 情侣餐具 | 两步：查看 → 翻面（内容在翻面后发放） |
| 活页本 | 三步：查看 → 翻开 → 继续翻页（线索在末步发放）；完成后重开可翻看任意已翻页 |
| 女主电脑 | 点击进入电脑桌子场景（不是普通文本物体） |
| 手账本（电脑桌） | 步骤与谜题/阅读界面联动（docs/08） |

## 5. 对外接口（其他系统只允许使用这些）

| 接口 | 类型 | 说明 |
|---|---|---|
| `object_investigated(object_id: String)` | 信号 | 物体全部步骤完成时发一次 |
| `object_step_completed(object_id: String, step_id: String)` | 信号 | 每个步骤首次完成时发 |
| `object_clicked(object_id: String)` | 信号 | 任意点击（含重复），用于反馈演出 |
| `refresh_region(region_id: String)` | 方法 | 事件效果执行后刷新物体显示状态（锁定/解锁/完成态） |

**禁止**：场景系统读取 truth_revealed / 完整度 / 事件配置；场景系统直接调用对话系统。
